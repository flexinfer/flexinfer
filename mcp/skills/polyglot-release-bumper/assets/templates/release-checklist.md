# Release Checklist

## Prep

- [ ] Working tree clean
- [ ] On correct branch
- [ ] CI green on HEAD

## Verify

- [ ] Run tests
- [ ] Run lint/format
- [ ] Build artifacts (if applicable)

## Version + Notes

- [ ] Bump version (if applicable)
- [ ] Update changelog / release notes

## Ship

- [ ] Commit
- [ ] Tag `vX.Y.Z`
- [ ] Push branch + tag
- [ ] Confirm CI/publish jobs
