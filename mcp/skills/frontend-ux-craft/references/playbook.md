# Frontend UX Craft Playbook

Use this playbook when a task needs more than correctness. The goal is to produce an interface that feels intentional, clear, and worth using.

## Sequence

1. Clarify the primary user action.
2. Audit the current surface for hierarchy, density, affordances, and state coverage.
3. Decide the visual thesis before editing.
4. Implement the smallest cohesive slice that expresses that thesis.
5. Review on desktop and mobile before calling it done.

## Visual Thesis Prompts

- What should feel fast, calm, confident, playful, or premium here?
- Which single visual idea should dominate: editorial, utilitarian, tactile, airy, dense, cinematic?
- What should the user notice first, second, and third?

## Non-Negotiables

- Strong spacing rhythm
- Clear primary action
- Accessible contrast and focus handling
- Loading, empty, error, hover, active, and disabled states
- Responsive behavior that still feels designed, not merely shrunk

## Red Flags

- Generic card soup
- Multiple visual languages competing in one surface
- Heavy decoration that does not improve comprehension
- Dense interfaces with no obvious reading path
- Motion that adds delay without feedback value
