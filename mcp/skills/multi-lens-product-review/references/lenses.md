# Multi-Lens Review Guide

Use these lenses independently first, then merge them.

## User Value

- What problem is being solved?
- Why would a user care right now?

## Hierarchy

- What is the first thing the eye lands on?
- Is the reading order intentional?

## Interaction

- Are affordances obvious?
- Do state changes reduce uncertainty?

## Copy

- Is the language concrete, concise, and confidence-building?

## Accessibility

- Can the flow be understood and operated inclusively?

## Performance / Leverage

- Which improvements have the best impact-to-effort ratio?
