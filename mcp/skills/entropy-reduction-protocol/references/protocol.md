# Entropy Reduction Protocol Notes

The protocol exists to keep complex work cumulative instead of noisy.

## Minimal Working Set

Keep these fields visible while working:

- Objective
- Current slice
- Constraints
- Files in play
- Next action
- Verification step
- Exit criteria

## Preferred Loop

1. Inspect a narrow surface.
2. Make one cohesive change.
3. Verify immediately.
4. Summarize the delta.
5. Decide whether to continue, split, or stop.

## When to Pause

- The current action no longer maps cleanly to the objective.
- New work keeps appearing faster than work is closing.
- Verification has drifted too far from the last edit.
- Multiple goals are being mixed in one patch.
