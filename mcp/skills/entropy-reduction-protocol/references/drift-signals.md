# Drift Signals

Treat these as warnings that entropy is taking over:

- Reading many files without updating the working theory
- Editing unrelated areas "while here"
- Switching between feature, refactor, and cleanup language
- Forgetting the original exit criteria
- Delaying validation until the end
- Accumulating open questions without recording them
- Repeating the same investigation from scratch

## Recovery Moves

- Rewrite the objective in one sentence
- Cut the slice in half
- Move speculative work to explicit follow-up
- Re-run the smallest useful verification step
- Summarize the current state before continuing
