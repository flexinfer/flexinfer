# Debt Item Execution Checklist

## Selection

- [ ] Debt item ID selected
- [ ] Impact and risk validated
- [ ] Scope boundaries documented

## Safety

- [ ] Baseline/characterization test added (or rationale documented)
- [ ] Rollback path identified
- [ ] Migration/compatibility risks reviewed

## Implementation

- [ ] Smallest end-to-end slice implemented
- [ ] Unrelated changes excluded
- [ ] Key decisions recorded

## Verification

- [ ] Local checks passed
- [ ] CI checks passed
- [ ] Performance/operational regressions checked (if relevant)
