# Loom Docs Standards

## Source Rules

- Prefer workspace sources: `path/to/file.ext:line` (and `:column` when helpful).
- When using command output as a source, include the exact command and a short excerpt.
- When using external sources, include the full URL and, if relevant, the date accessed.
- Avoid “common knowledge” claims about the workspace; if it matters, source it.

## Writing Rules

- Keep “Goal / Non-Goals / Acceptance Criteria” explicit in specs and plans.
- Separate “facts found” from “assumptions”.
- Track open questions; do not silently decide without recording a decision.

## Minimal Deliverables

When doing structured work, prefer producing (or updating) these files:

- `00-workspace-snapshot.md` (generated)
- `00-mcp-inventory.md` (tool inventory)
- `10-research.md` (when exploring)
- `20-product-spec.md` (when defining “what”)
- `30-implementation-plan.md` (when defining “how”)
- `40-decisions.md` (when choosing)
- `50-worklog.md` (while executing)
