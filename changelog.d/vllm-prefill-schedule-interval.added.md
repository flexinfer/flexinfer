- New vLLM config key `prefillScheduleInterval` (→ `--prefill-schedule-interval`): admit prefill once every N engine steps and decode alone in between, so a request decoding beside a long prefill is not held to one stream chunk per long-prefill chunk. Rendered only above 1 and only on a Model that declares `vllmVersion` 0.33.0 or later; any other use is refused with `ConfigInvalid`. No lane sets it yet, and it reaches the cluster only with a controller build that includes it.
