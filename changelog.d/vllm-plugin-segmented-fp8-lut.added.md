- **vLLM plugins: fp8 KV converted through a table on gfx11 (opt-in, off by default).** `FLEXINFER_SEGMENTED_FP8_LUT=1` (plugin-common 0.7.0, text plugin 0.13.0) swaps the fp8 → fp16 conversion in vLLM's ROCm segmented attention stage kernel for a 256-entry table gather. Triton 3.8 lowers the stock conversion to nine compare-and-select pairs per element, which made fp8 attention 5.8–6.1× the fp16 time per decode step on the XTX; the table measured 1.17×, bit-identical to stock (kill test `gfx1100-fp8-attention-convert-2026-11-24`). At boot the plugin rewrites vLLM's `segmented_attention.py` (only a source it knows by sha256, today vLLM 0.33.0+rocm72), routes one-byte KV launches and compiles to the rewritten kernel, gives fp8 its own tuning table and keeps the tuner's kernel-unload scope covering it. fp16 caches launch the upstream kernel unchanged. The image build now reports whether the kernel is installable. No lane sets the flag; the engine canary is row `gfx1100-xtx-128k-fp8-lut-2026-11-24`.
