- Honor the `flexinfer.ai/activate-requested-at` annotation on v1alpha2 `Model`: the controller now adopts a request strictly newer than the new `status.activationRequestedAt` watermark and treats it as demand for a bounded 30-minute window, waking a scale-to-zero serverless model without pinning `spec.serverless.minReplicas`. Previously the annotation was written by tooling (loom-core's `flexinfer_activate_model`) but read by nothing, so "activation" only ever bumped `resourceVersion` to trigger a reconcile and was a no-op on an idle model. Malformed timestamps are ignored rather than read as "now", stale annotations cannot resurrect an idle model, and the gaming-lease / KV-eviction / shared-GPU overrides still take precedence. Activation also feeds the shared-GPU election and the runtime loader through a single `demandTime` accessor (proxy `LastActiveTime` or an in-window activation request, whichever is later); without that it would be inert for every shared-GPU member, which on the live fleet is 22 of 25 models and every currently-idle one. `demandTime` returns `LastActiveTime` unchanged for any model with no in-window request, so existing election behavior is unaffected.
