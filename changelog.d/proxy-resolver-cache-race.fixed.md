The proxy's model resolver no longer races its own cache refresh (`internal/proxy/model_resolver.go`). Each refresh (every 5 s for service labels, 5 s for aliases) assigned a fresh `sync.Map` over the field that concurrent requests were reading, a data race, and then refilled it, so a request arriving mid-refresh could miss a service label or alias it had resolved a moment earlier and get a spurious `model_not_found`. Both caches are now built as immutable snapshots and published with one `atomic.Pointer` store; readers see the old cache or the new one, never a partial one. Regression test: `TestModelResolverRefreshIsInvisibleToConcurrentReaders` (fails under `-race` before the change).
