- `flexinfer-bench swap`, the swap-floor profiler for KT-SWAP (D1). It swaps lanes in and out of one runtime pod through the runtime API and records, per swap: unload and drain, the admission wait while the runtime still counts the outgoing lane's VRAM, the load split by the substages the runtime reports (`Spawn`, `LoadingWeights`, `Compiling` summed over both visits, `ProfilingKV`, `Ready`), the KV profile, and the first token after Ready. On text lanes it also runs greedy hashes and decode on the three S3 parity prompts, with a fresh `cache_salt` per probe. It compares against a `--probe-url` baseline of the Deployment lane, scores the KT-SWAP bars, and writes a JSON report and a matrix row. Lanes are load payloads or Model manifests rendered by the controller's payload builder. Subcommands register from their own file (`cmd/flexinfer-bench/subcommands.go`); `main.go` only dispatches. Docs: `docs/user/swap-profiler.md`.
