- Check diffusers output for NaN pixels before it is encoded. On 2026-11-19 the Qwen-Image 2.1 lane, launched in the 7900 XTX runtime pod, decoded NaN in its warmup, went Ready anyway, and answered its first render with HTTP 200 and a garbage PNG of flat and noisy tiles. `build/server-diffusers.py` now asks image pipelines for float output (`output_type="np"`), counts NaN with one `np.isfinite` pass, and converts sound output with the pipeline's own `numpy_to_pil`, so normal renders keep the same bytes. Only NaN is caught: diffusers clamps the decode to [0, 1] first, so an Inf arrives as 0 or 1. Wan video frames are checked the same way. An image request with NaN output is rendered once more (`NONFINITE_RENDER_RETRIES`, default 1; same seed when the request has one) and otherwise fails with HTTP 500 and a `nonfinite_output` detail. Video fails with the 500 at once (`NONFINITE_VIDEO_RETRIES`, default 0), because a retry would outlast the proxy's first-byte budget. A NaN warmup pass is repeated (`WARMUP_NONFINITE_RETRIES`, default 2, inside the startup probe window; set 0 for a slow-loading lane) and logged; with `WARMUP_NONFINITE_STRICT=1` startup then fails so the lane never goes Ready. `GET /health` reports the counts under `nonfinite`. `NONFINITE_GUARD=0` turns all of it off, and is needed for an AutoPipeline-fallback lane such as DeepFloyd IF whose "pil" output adds steps. `/v1/images/edits` and `/v1/images/variations` are not guarded. The cause of the 2026-11-19 NaN is not known, and a repeated warmup is not known to clear it.

- `scripts/render-gate.py`: the multi-render gate from that run, made repeatable. It renders seeds S, S+1, S+2 and S again through `/v1/images/generations`, saves the PNGs and a JSON report, and fails on transparency, mostly-flat 64x64 blocks, channel statistics, size, HTTP status, or a seed-S mismatch above 2 levels. The earlier standard-deviation and mean rule alone passed the 2026-11-19 garbage; this gate fails both garbage images and passes the sound ones. `--verdict report.json` re-scores a saved run and `--score` scores files by hand; `--max-flat-tile-share` and `--allow-transparent` relax the checks for prompts that ask for plain or transparent images. Exit status is 0 on a pass, 1 on a failed gate and 2 on an error.
