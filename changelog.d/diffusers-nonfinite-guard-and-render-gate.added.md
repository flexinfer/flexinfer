- Check diffusers output for NaN/Inf pixels before it is encoded. On 2026-11-19 the Qwen-Image 2.1 lane, launched in the 7900 XTX runtime pod, decoded NaN in its warmup, went Ready anyway, and answered its first render with HTTP 200 and a garbage PNG of flat and noisy tiles. `build/server-diffusers.py` now asks image pipelines for float output (`output_type="np"`), counts non-finite values with one `np.isfinite` pass, and converts sound output with the pipeline's own `numpy_to_pil`, so normal renders keep the same bytes. Wan video frames are checked the same way. A non-finite request is rendered once more with the same seed (`NONFINITE_RENDER_RETRIES`, default 1) and otherwise fails with HTTP 500 and a `nonfinite_output` detail. A non-finite warmup pass is repeated (`WARMUP_NONFINITE_RETRIES`, default 2) and logged; with `WARMUP_NONFINITE_STRICT=1` startup then fails so the lane never goes Ready. `GET /health` reports the counts under `nonfinite`. `NONFINITE_GUARD=0` turns all of it off. The cause of the 2026-11-19 NaN is not known, and a repeated warmup is not known to clear it.

- `scripts/render-gate.py`: the multi-render gate from that run, made repeatable. It renders seeds S, S+1, S+2 and S again through `/v1/images/generations`, saves the PNGs and a JSON report, and fails on transparency, mostly-flat 64x64 blocks, channel statistics, size, HTTP status, or a seed-S mismatch above 2 levels. The earlier standard-deviation and mean rule alone passed the 2026-11-19 garbage; this gate fails both garbage images and passes the sound ones. `--verdict report.json` re-scores a saved run and `--score` scores files by hand.
