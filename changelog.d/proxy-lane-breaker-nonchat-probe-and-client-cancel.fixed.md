The proxy's lane breaker probes lanes that serve neither chat nor embeddings (images, audio, rerank; `flexinfer.ai/serve-paths`) on `GET /health` instead of `POST /v1/chat/completions`, which a diffusers lane answers with 404 and which therefore held the Qwen-Image lane's breaker open for as long as the lane lived. A client that cancels before the lane's first-byte budget has run out no longer counts as a lane failure: the caller still gets a timeout, but a 40-step render abandoned by an impatient client cannot trip the breaker. The budget timer alone counts a silent upstream.
