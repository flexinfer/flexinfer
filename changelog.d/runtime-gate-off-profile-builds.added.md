- The runtime pin-drift report (`scripts/check-runtime-pin-drift.py`) now reports an off-CI overlay digest as an **off-profile build** instead of passing it as a build of its profile. Only the floating tag or `<floating>-<commit sha>` counts as a profile build, so `rocm-gfx906-humanizer-<sha>` on the gfx906 DaemonSet is now flagged. Off-profile builds fail `--strict` and are listed under `off_profile_builds` in the JSON. Each one gets a warning in its promotion proposal (`scripts/propose-runtime-promotions.py`) and a marker in the proposal index. The report also flags split pins, where a GPUProfile `runtime.image` differs from the DaemonSet image for the same arch, as report-only.
- `scripts/check-runtime-patch-contracts.py` checks that every runtime publish job hardcoding build args or a `runtime.env` heredoc matches `build/runtime.yaml`. This covers `publish_runtime_rocm_gfx906` and the gfx1100 unified, serving, gaming and native-W4A16 jobs. A profile-level version key overrides the global one. The comparison includes base image, Go, llama.cpp and Ollama versions, the `INCLUDE_*` flags, transformers and vLLM args, the Dockerfile, the pushed tags, and every `runtime.env` key. Divergences already on master are listed as known and printed as warnings.
