The Qwen3.5 text-only vLLM plugin (0.8.0) loads on vLLM 0.26: it resolves the flash-linear-attention kernel module from either layout (`vllm.model_executor.layers.fla.ops` on ≤ 0.23, `vllm.third_party.flash_linear_attention.ops` on ≥ 0.26), fails loudly on an unknown layout, and skips the MoE GPTQ expert-loader hook when the runtime has no `load_fused_expert_weights` (dense lanes only). The native-W4A16 image build now executes the plugin's `register()` against the built vLLM, and the plugin directory is a rebuild trigger for that image.
