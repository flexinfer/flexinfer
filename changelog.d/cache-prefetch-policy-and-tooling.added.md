Added `spec.cache.prefetch` to the v1alpha2 `Model` CRD so operators can trade cache storage against first-request latency per model: `policy` (`Eager`, the pre-existing and still-default behavior; `OnDemand`, which defers staging until something wants the model; `Disabled`, which stages only on request), `priority`, and `idleTTL`. A new `flexinfer.ai/prefetch-requested-at` annotation requests immediate staging whatever the policy says, and clears a failed staging Job so it retries — running and succeeded Jobs are left alone. `status.cache` now reports `prefetchPolicy`, `prefetchDeferred`, `lastPrefetchTime`, and `prefetchRequestedAt`.

`flexinfer cache` grew the commands to drive it: `prefetch` (stage weights without starting the GPU pod, with `--wait`), `wait` (block until staged, non-zero exit on failure or timeout), `capacity` (PVC pressure, which models share a volume, and reclaim candidates past their `idleTTL`), and `evict` (confirm-gated PVC reclaim, refused unless the PVC was auto-created for that one model and no other model uses it). `flexinfer cache status` now leads with v1alpha2 `Model` cache state — previously it showed only v1alpha1 `ModelCache` resources, so a v1alpha2 fleet's cache state was invisible — and still lists `ModelCache` pipeline resources underneath when any exist.
