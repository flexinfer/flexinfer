Added the `gfx1100-serving-v032` runtime persona (`build/Dockerfile.runtime-serving-v032`, CI `publish_serving_rocm_gfx1100_v032`): the vLLM 0.32 native-W4A16 stack plus the runtime supervisor and the diffusers and snac servers in one image, so the gfx1100 runtime DaemonSets can host the 0.32 text lanes instead of one Deployment per lane. The overlay cannot move any package of the vLLM stack (pip constraints from a pre-overlay snapshot), and `build/scripts/verify_runtime_serving_stack.py` checks the stack and every runtime spawn target at build time. Nothing consumes the image yet.
