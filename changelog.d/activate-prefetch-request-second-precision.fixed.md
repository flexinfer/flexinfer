- Stop the `flexinfer.ai/activate-requested-at` and `flexinfer.ai/prefetch-requested-at` watermarks from re-adopting the same request on every reconcile. Tooling writes RFC3339**Nano**, but `metav1.Time` serializes at second precision, so the parsed request compared strictly newer than the watermark the API server handed back — forever. The controller rewrote status and re-emitted its event in a hot loop; one live activation on 2026-09-22 produced an `ActivationRequested` event with `count=25`. Both parsers now truncate to the precision that actually round-trips.
