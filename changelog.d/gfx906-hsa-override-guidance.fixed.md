The gfx906 `HSA_OVERRIDE_GFX_VERSION` guidance now agrees everywhere: leave it unset. KFD reports the Radeon VII natively as gfx906 (`gfx_target_version 90006`), and the live runtime pod, its manager process and every llama-server ran without the key on 2026-10-30. An empty inherited value can hide the GPU, which is why the runtime entrypoint removes it. The gfx906 GPUProfile header, `docs/dev/gfx906-gpu-support.md` (which listed `9.0.6` as set by the profile and said the card reports gfx900), the platform slice doc and the gfx906 FLUX notes are corrected. The stale "runtime is paused (Track B)" note on the gfx906 vLLM `audioTranscription` capability is gone. The retired mlc-llm backend entries stay in both GPUProfiles, now with a comment: the backend is still registered, and the generic profile lookups would read them for any mlc-llm Model.
