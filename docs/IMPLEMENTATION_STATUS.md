# Implementation status

This page no longer keeps its own status report. It points to the documents that do, and lists what landed most recently. Last checked against `master` on 2026-11-01.

FlexInfer runs a live k3s cluster's LLM, embedding, rerank, speech, image and video lanes on RX 7900 XTX (gfx1100), Radeon VII (gfx906) and GTX 980 Ti (Maxwell) cards. Each question has one source of truth:

| Question | Where the answer lives |
|---|---|
| What is served, on which card and serving path | The README: [Supported GPU classes](../README.md#supported-gpu-classes) (its "What runs where" table) and [Serving paths](../README.md#serving-paths) |
| State of the gfx1100 and gfx906 lanes | §1 of the [2026-11 feature design](../.loom/10-research-gfx1100-gfx906-next-differentiators-2026-10-31.md) |
| What is certified, per GPU class, backend and lane | [certification-matrix.json](certification-matrix.json), generated by `make certify-matrix`. Fields and derivation rules: [specs/certification-matrix.md](specs/certification-matrix.md) |
| Kill-test verdicts and promotion evidence | [.loom/60-validation-matrix.md](../.loom/60-validation-matrix.md), one dated row per test, written before the data |
| What comes next | [ROADMAP.md](../ROADMAP.md) and §6 to §10 of the design |

## Deliveries of 2026-10-31 and 2026-11-01

These are the design's features D1 to D4, D6 and D7. MR numbers refer to [merge requests on GitLab](https://gitlab.flexinfer.ai/services/flexinfer/-/merge_requests). The merged code is behaviour-neutral until a lane opts in or a Draft is applied.

"Window" means the maintainer-run window on or after 2026-11-06 00:15Z, after the RX 7900 XTX hardware soak verdict. Every matrix row below is still `pending`: its pass rule is written, and the run waits for the window or for a canary the maintainer applies.

| Feature | Merged | Draft, held for the maintainer | Matrix row |
|---|---|---|---|
| **D1** Instant flex card: in-pod switching on the XTX runtime | !1224 runtime pin guard, !1227 `flexinfer-bench swap` profiler, !1232 `7ae8e92f` prewarm and certification, !1240 window plan | Window: !1234 XTX runtime repin, !1235 warm lane in-pod, !1236–!1239 image, video and audio lanes in-pod (these four are also blocked on Python packages missing from the runtime image) | `gfx1100-xtx-inpod-swap-2026-11-01` (KT-SWAP) |
| **D2** Scale-to-zero contract | !1210 typed error envelope, !1213 cold capability descriptor, !1216 `InferenceJob` CRD, !1218 job API and runner, !1219 job GC, metrics and CLI, !1220 KT-JOBS harness | Window: !1221 proxy and controller roll with the job API on | `proxy-async-jobs-2026-10-31` (KT-JOBS) |
