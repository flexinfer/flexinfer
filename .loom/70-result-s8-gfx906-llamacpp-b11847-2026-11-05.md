## Pass rule vs outcome

The rule was written 2026-11-05, before the canary, in row `gfx906-llamacpp-b11847-2026-11-05`.

| Criterion | Outcome |
|---|---|
| (1) embeddings cosine ≥ 0.999, same dimension | **pass**: min 0.99979 (gte), all dimensions equal |
| (1) rerank same order and max \|Δscore\| ≤ 0.02 | **two literal misses.** bge-reranker: same order, but max \|Δ\| 0.033 on a logit scale (−11 … +1.7), 1.65 % relative. The 0.02 bound assumed 0–1 scores. qwen3-reranker: \|Δ\| 0.0075 passes, but ranks 5 and 6 swap (docs 2 and 7, scores 8.4e-5 vs 8.7e-5); ranks 1–4 and 7–8 are identical |
| (1) generative decode ≥ 0.9× b11335; humanizer loads and answers | **pass**: gemma 0.97×, orpheus 1.002× (follow-up), humanizer 0.99× with identical text |
| (2) b11847 VRAM peak ≤ b11335 + 64 MiB | **pass**: worst +6.5 MiB |
| (3) ≤ 3 compute queues per llama-server, card ≤ 24 | **pass**: 3 everywhere, card peak 20 (sampler; the harness column is wrong, see above) |
| (4) p95 ≤ 1.10× b11335 | **pass**: worst 1.05× (bge-large sequential); the three LM-head lanes are faster |
| (5) no abort; live gte p95 per b11847 arm ≤ 1.2× or + 20 ms of its b11335 arm | **no abort.** One literal miss: the qwen3-embedding-4b arm read 77.7 vs 57.6 ms (+20.1 ms) on 13 probes, where p95 is the single slowest probe and p50 fell 45.9 → 33.3 ms. The 59-probe follow-up reads 30.0 vs 31.9 ms. Every other arm passes |

**Verdict: conditional.**
- **What passed:** the substance — LM-head savings, no VRAM or queue growth, no latency regression, and embedding parity at ≥ 0.9998.
- **What missed, on the letter:**
  - two rerank parity bounds that were mis-scaled for these heads;
  - one 13-sample tail reading that its 59-sample rerun does not reproduce.
- **Owner decision:** accept these as calibration misses and promote, or ask for a rerank parity rerun with a scale-aware bound (relative \|Δ\| ≤ 2 %, top-4 order). The repin is a window action in any case.
