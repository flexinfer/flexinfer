# ICP v1 — Slice 0 Kill-Test

**Date:** 2026-06-21
**Purpose:** one tight segment to run the 2-week kill-test (≥2 qualified discovery calls). See [30-implementation-plan-gtm-engine.md](30-implementation-plan-gtm-engine.md) Slice 0.

## The offer (what we're selling)
A fixed-scope **3-week "agent-enablement sprint"**: we stand up an **automated, self-hosted outbound lead-gen agent on the client's own stack** — the same engine we run on ours — with a live pipeline dashboard. Dogfood angle: *the system that contacted you is the system we build for you.*

## Segment (pick ONE — narrow on purpose)
**Seed–Series-A B2B software startups, ~10–40 headcount, founder-led or thin sales motion, no dedicated RevOps/SDR, already using AI tools internally.**

The pain is acute and universal for this segment: they need pipeline, the founders are doing outreach manually between building, and they have no time to build automation. They're technical enough to appreciate a self-hosted/private agent and cost-conscious enough to prefer it over per-seat SaaS.

### Firmographics
- Stage: pre-seed → Series A (raised in last ~18 months is a strong signal)
- Size: 10–40 employees; ≤3 in sales
- Type: B2B SaaS / dev tools / vertical AI apps
- Geo: US (timezone overlap), English-first
- Tech posture: already pays for AI tooling; values data control / self-hosting

### Target personas (decision-maker for this offer)
1. **Founder / CEO** (primary — owns revenue at this stage)
2. **Head of Growth / first GTM hire** (if one exists)
3. **Technical co-founder / CTO** (resonates with self-hosted + agent angle)

### Trigger signals (rank prospects higher if present)
- Recently raised (seed/A) — has budget + pipeline pressure
- Hiring for "founding AE / GTM / growth" — feels the gap, no system yet
- Founder posting about doing outbound / "looking for customers" manually
- Ships an AI product (understands the value of agents → easier sell)
- Small/no marketing team (we fill a real hole, not competing with a function)

### Qualifying criteria (a "qualified" discovery call = all of these)
- B2B, has a definable ICP of their own (so an outbound agent can target it)
- A human with budget authority on the call (founder or growth lead)
- Currently doing outbound manually OR not at all (greenfield for automation)
- Acknowledges pipeline as a current priority

### Disqualifiers (do not pursue)
- Pure B2C / PLG-only with no outbound motion
- >75 employees with an existing RevOps/SDR team + tooling (we'd be a rip-and-replace)
- Agencies/consultancies selling the same thing
- Non-English / no US-timezone overlap
- Pre-product / no ICP of their own yet

## Messaging angles (for the personalization model)
- **Dogfood proof:** "This email was sourced + drafted by the same automated agent we'd build for you."
- **Time-back:** founder hours reclaimed from manual prospecting.
- **Control/cost:** self-hosted, your data, no per-seat SaaS tax.
- **Concrete CTA:** a 20-min discovery call; offer 2–3 specific slots.

Keep emails: ≤120 words, one specific observation about THEIR company (from enrichment), one sentence of offer, one clear CTA. No fluff, no "I hope this finds you well."

## Sourcing seeds (Tavily query starting points)
- `"seed funded" B2B SaaS startup 2025 2026 site:techcrunch.com`
- `Series A AI startup hiring "founding account executive"`
- `"we just raised" seed B2B SaaS founder outbound`
- `dev tools startup seed round 2026`
- (refine after first run based on hit quality)

## Kill-test metric
Count of tracked prospects reaching **status = `booked`** within 14 days of first send.
**Gate: ≥2 booked qualified calls → proceed to Slice 1. <2 → STOP, pivot to content-inbound.**
